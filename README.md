## Projects

### Distributed Rate Limiter
`Node.js` `Express` `Redis` `Lua`

Token Bucket rate limiter with per-client Redis state and atomic Lua scripts. Enforces configurable burst capacity, refill rates, HTTP 429 responses, rate-limit headers, and Retry-After semantics. Benchmarked at **2,100+ req/sec**, **4.17 ms avg latency**, **7 ms p99** across 22K+ requests.

[View Repository](https://github.com/Krishna-Rao-dev/Rate-limiter)

---

### Self-Hosted File Management System
`React` `Node.js` `PostgreSQL` `AWS S3`

Full-featured file platform with secure auth, RBAC, hierarchical folders, presigned S3 uploads/downloads, multipart transfers, and integrity verification. PostgreSQL schema isolates user data, folder structure, and file metadata from S3 storage. Every file operation validates ownership or sharing permissions before issuing short-lived S3 URLs - bucket stays private throughout.

[View Repository](https://github.com/Krishna-Rao-dev/self-hosted-file-system)

### BFSI Compliance & Fraud Detection

End-to-end compliance intelligence platform using Tesseract OCR and LLM-based extraction to automate regulatory document processing and generate audit-ready compliance reports. Backend deployed on EC2, frontend hosted on S3.

### Call2Cart - AI Phone Ordering Agent
`React` `FastAPI` `LangGraph` `Twilio` `MongoDB` `Redis`

Conversational AI agent that automates restaurant ordering entirely over phone calls - customers place orders, modify items, provide delivery details, and confirm purchases with no human intervention. Redis-backed menu caching cut database read latency from **~10s to 3s**. Includes MongoDB customer profiling, real-time order sync to a restaurant dashboard, and Twilio SMS notifications.

[Demo](https://docs.google.com/videos/d/1PLUg-sINYZasM0DZrdQ-p98ZnHEy1ddtG01UmT6yjtY/edit?usp=sharing) | [Repository](https://github.com/Krishna-Rao-dev/Google_APL)
